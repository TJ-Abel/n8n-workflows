# n8n Automation Workflows — Emmanuel Abel

Production-ready automation workflows built with n8n.

## Folders
- **ai-agents/** — Conversational AI agents (OpenAI, Gemini)
- **automation/** — Form automations, notifications, scheduling
- **data-processing/** — Lead qualification, summarization, reporting

## How to Import
1. Download the .json file
2. In n8n click Import from file
3. Reconnect your own credentials
4. Activate the workflow

> Credentials not included — connect your own accounts after importing.
